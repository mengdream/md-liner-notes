bohemianvoodoo 的第二张专辑，2012 年底在 Playwright 发行，常被乐迷视为他们的代表作之一。如果喜欢 MOMENTS，很值得回头补听这张，感受这支乐队一路的变化：比起 MOMENTS 的色彩斑斓，这张更明快、更洒脱。厂牌的介绍是：以一段抢耳的吉他 riff 开场，13 首、66 分钟，有动人的旋律，也有高张力的激烈演奏。开篇的 Adria Blue 至今仍是乐队的招牌曲。

Notes

那时的 bohemianvoodoo

乐队 2008 年在横滨组成，2010 年在 P-VINE 发行首张全长专辑 Lapis Lazuli。两年后的 SCENES 是他们在 Playwright 的第一张，阵容是 bashiry（吉他）、木村イオリ（钢琴、键盘）、Nassy（贝斯）和创团鼓手井上孝利；2013 年井上离队，由山本拓矢接替。对一支年轻的爵士乐队来说，这张卖得少见地久。Adria Blue 在 YouTube 上的播放超过五百万次，在日本器乐圈里很罕见，也把不少海外听众带到了他们面前。

从 SCENES 到 MOMENTS

两张之间隔了六年多：2013 年换了鼓手，2014 年出了 Aromatic 并登上 Blue Note Tokyo，2017 年的现场精选 echoes 拿下 JAZZ JAPAN AWARD 的ニュー・ジャズ部门年度专辑，2019 年才有 MOMENTS。早年他们常被归进“クラブジャズ”，到了 MOMENTS，木村イオリ直说不想再被这样叫，曲风也放得更宽，拉丁、放克之外还加了铜管。先听 MOMENTS 再回头听 SCENES，能听出同一种“会唱歌”的旋律感，只是这里更明快。
